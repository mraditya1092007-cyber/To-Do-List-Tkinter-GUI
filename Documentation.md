Project Name: To-Do List (Tkinter GUI)

Description:
This project is developed using Python and Tkinter. It provides a graphical interface for managing daily tasks. Users can add, delete, and clear tasks easily.

Tools Used:
- Python 3
- Tkinter
- Pydroid 3
- GitHub

Outcome:
The application successfully manages tasks through a graphical interface and demonstrates Python GUI development using Tkinter.
