## Project Scope

This project is a Python-based To-Do List application developed using Tkinter GUI. It allows users to add, delete, and manage daily tasks through a simple graphical interface.

---

## Project Description

The To-Do List application helps users organize their work efficiently. Users can add tasks, remove selected tasks, and clear all tasks from the list.

---

## Features

1. Add New Tasks
2. Display Tasks in List
3. Delete Selected Task
4. Clear All Tasks
5. User-Friendly GUI
6. Confirmation Dialog Box
7. Scrollable Task List
